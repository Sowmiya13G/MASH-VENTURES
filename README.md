# Next.js 3D Cinematic Website — Skills & Rules

This package gives an AI coding agent project-level guidance for building a premium, dark, cinematic website with original interactive 3D robot characters.

## Included
- `AGENTS.md` — general project instructions for AI coding agents that support AGENTS.md.
- `.cursor/rules/3d-cinematic-website.mdc` — Cursor project rule.
- `skills/3d-cinematic-website/SKILL.md` — detailed reusable implementation skill.

## Install
1. Extract this ZIP into the root of your existing Next.js project.
2. Keep your existing source code and configuration files.
3. Open the project in Cursor (or another compatible AI coding tool).
4. Ask the agent: **“Read AGENTS.md and the 3D cinematic website skill/rules. Inspect my existing project, then implement the first milestone: a responsive, performant 3D robot hero. Do not overwrite existing files without checking them first.”**

## Important
- The package does not include 3D models. Source or commission models with explicit commercial web-use rights.
- Use original robot designs. Do not copy Transformers characters, names, logos, or recognizable designs without appropriate written authorization.
- The code agent must inspect your current Next.js and React versions before choosing dependency versions.
