# GoDaddy CI/CD Deployment Guide — MASH VENTURES

This guide explains how the automated GitHub Actions CI/CD pipeline deploys MASH VENTURES directly to GoDaddy hosting on every push to the `main` branch.

---

## 1. How It Works

The workflow file is located at [`.github/workflows/deploy-godaddy.yml`](../.github/workflows/deploy-godaddy.yml).

1. **Automated Verification**: Runs `npm run typecheck` and `npm run lint` on Ubuntu runner.
2. **Standalone Build**: Builds Next.js using `output: "standalone"` to generate minimal server and client artifacts.
3. **Artifact Assembly**: Bundles `.next/standalone`, `.next/static`, and `public` assets with a `tmp/restart.txt` reload hook.
4. **Direct Deployment**: Deploys the built files directly to your GoDaddy server via **FTP/SFTP** (or **SSH** for VPS).
5. **Zero Downtime Restart**: Touching `tmp/restart.txt` signals GoDaddy's Passenger/Node.js manager to reload the application seamlessly.

## 2. GitHub Repository Secrets Setup

Go to your GitHub repository:
**Settings &rarr; Secrets and variables &rarr; Actions &rarr; New repository secret**

### A. For GoDaddy cPanel / Shared Hosting (FTP / SFTP)

| Secret Name | Value Example | Description |
| :--- | :--- | :--- |
| `GODADDY_FTP_SERVER` | `ftp.mashventures.in` or `192.168.x.x` | Your GoDaddy FTP host / IP address |
| `GODADDY_FTP_USERNAME` | `deployer@mashventures.in` | GoDaddy cPanel FTP username |
| `GODADDY_FTP_PASSWORD` | `YourStrongPasswordHere` | GoDaddy FTP account password |
| `GODADDY_FTP_PORT` | `21` (or `22` for SFTP) | Port (optional, defaults to 21) |
| `GODADDY_FTP_PROTOCOL` | `ftp` (or `ftps` / `sftp`) | Protocol (defaults to `ftp`) |
| `GODADDY_REMOTE_PATH` | `/public_html` or `/nodeapp` | Target directory configured for your Node app |

### B. For GoDaddy VPS / Dedicated Server (SSH)

If you are using a GoDaddy Linux VPS with SSH & PM2:

| Secret Name | Value Example | Description |
| :--- | :--- | :--- |
| `GODADDY_SSH_HOST` | `192.168.x.x` | Server IP or hostname |
| `GODADDY_SSH_USER` | `root` or `ubuntu` | SSH user |
| `GODADDY_SSH_KEY` | `-----BEGIN OPENSSH PRIVATE KEY...` | SSH Private Key (or use `GODADDY_SSH_PASSWORD`) |
| `GODADDY_REMOTE_PATH` | `/var/www/mash-ventures` | Project directory on server |

### C. Application Environment Secrets (Optional)

| Secret Name | Description |
| :--- | :--- |
| `RESEND_API_KEY` | Resend API key for enquiry emails (`re_...`) |
| `CONTACT_TO_EMAIL` | Inbox to receive customer enquiries (`mashventuresindia@gmail.com`) |
| `CONTACT_FROM_EMAIL` | Verified sender in Resend |
| `ENV_PRODUCTION` | Full content of `.env.production` (if you want to inject all environment variables at once) |

## 3. GoDaddy cPanel Node.js Configuration

If using GoDaddy cPanel:

1. Log in to your **GoDaddy cPanel**.
2. Under the **Software** section, click **Setup Node.js App**.
3. Click **Create Application**:
   - **Node.js version**: Select **20.x** (or latest available).
   - **Application mode**: Select **Production**.
   - **Application root**: e.g., `nodeapp` (or your destination folder matching `GODADDY_REMOTE_PATH`).
   - **Application URL**: Select `mashventures.in` (or your desired subdomain/domain).
   - **Application startup file**: Enter `server.js` (generated by Next.js standalone build).
4. Click **Create**.
5. When the GitHub Action deploys, the files are uploaded directly to this folder, and `tmp/restart.txt` reloads the app automatically without needing to restart it manually in cPanel!

## 4. Triggering a Deployment

1. **Automatic**: Push any changes to the `main` branch:
   ```bash
   git add .
   git commit -m "Configure GoDaddy CI/CD pipeline"
   git push origin main
   ```
2. **Manual**: Go to **GitHub &rarr; Actions &rarr; "Build & Deploy to GoDaddy" &rarr; Run workflow**.
